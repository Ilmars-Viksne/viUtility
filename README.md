# viUtility

A collection of focused, production-quality command-line utilities.

## Utilities

- **Text File Collector** (`text-file-collector/`): A CLI utility that recursively collects non-binary text files into one combined text file.
- **PDF File Collector** (`pdf-file-collector/`): A non-destructive Python CLI for collecting, extracting, inserting, removing, reordering, reversing, splitting, merging, and composing pages from PDF files.
